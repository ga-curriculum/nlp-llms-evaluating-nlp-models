## About
An introduction to common benchmarks, metrics, and other key factors for selecting and evaluating the performance of LLMs.

## Learning Objectives

*You will be able to:*

- Describe use cases and common methods for benchmarking.
- Evaluate performance of NLP models.
- Appraise the cost impacts of various models.
- Assess risk and impact of bias in each model.

- Python

- Understand, run, and evaluate classification metrics in `scikit-learn`
- Comfort with Hugging Face Pipeline API for NLP tasks.
